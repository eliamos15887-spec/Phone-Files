# קבצים מהטלפון (PhoneFiles)

**להורדת הגרסה האחרונה:** [PhoneFiles-latest.zip](https://github.com/eliamos15887-spec/PhoneFiles/raw/main/releases/PhoneFiles-latest.zip)

תוכנה להעברת תמונות, סרטונים ומסמכים מהטלפון ומכונן חיצוני למחשב (Windows), עם אפשרות למחוק מהטלפון אחרי בדיקה שהקובץ הועתק, ולשונית "שיחות מוקלטות" עם יומן שיחות שאפשר לחפש לפי שם או מספר.

התקנה: מורידים את הקובץ, פותחים את ה-zip ומעתיקים את PhoneFiles.exe לכונן שאינו C (למשל D:\PhoneFiles), ואז מפעילים אותו.

- `latest.json` – הגרסה האחרונה
- `releases/` – כל הגרסאות
